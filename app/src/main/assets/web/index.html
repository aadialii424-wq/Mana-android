    📖 SETUP GUIDE — Free API key (2 minute)
    1. Phone browser mein aistudio.google.com kholo → Google account se sign in karo
    2. Get API key → Create API key → key copy karo (AIza... se shuru)
    3. ⚙️ Settings tab → API key paste → SAVE. Bas — Maya online dimaag ke saath! (Bilkul free — roz sainkdon requests normal use ke liye kaafi.)
    🌐 FREE HOSTING — App jesa install karne ka tarika
    1. Poora maya folder (index.html, manifest.json, sw.js, icons) download karo
    2. app.netlify.com/drop kholo (free account) → folder drag & drop karo → live link mil jayega (HTTPS)
    3. Wo link phone ke Chrome mein kholo → menu (⋮) → Add to Home screen / Install app → Maya ka apna icon, full screen app ban jayegi ✅
    GitHub Pages se bhi free host ho sakta hai (thoda technical). Hosting ke baad offline bhi chalegi — service worker app ko cache kar leta hai.
    ⚠️ HONEST LIMITS — jo Maya nahi kar sakti (abhi)
    • PWA/browser version mein system alarm jaise controls nahi — APK version mein real alarm + system timer milta hai
    • Wake word background service ab available — Settings se ON karo
    • AI ke jawab ke liye internet chahiye; local commands offline bhi chalte hain
    • Mic sirf HTTPS ya local file par chalta hai
